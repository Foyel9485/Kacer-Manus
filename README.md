# কাছের মানুষ (Foyel) — Starter Website

This is a static first-step UI preview.

Included: responsive green/white homepage, Bangla/English toggle, country and optional city filtering against clearly marked sample profiles.

Important: sign-up/login, database-backed profiles, server-enforced phone privacy, and private chat are not implemented yet. Do not enter real personal information in this demo. Add and test these features with Supabase before inviting real users.

For GitHub, commit `index.html` to the repository root. For Cloudflare Pages, deploy this folder as a static site.
